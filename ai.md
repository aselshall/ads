## [Project 2 AI Flooding](https://mewcha1.github.io/NBI): Integrating Bathtub Inundation Modeling and Large Language Models for Coastal Flood Screening in South Florida

### Project Summary
The LLM-powered decision-support dashboard will transform the existing Python-based Naples bathtub inundation model into an interactive regional platform for Collier, Lee, and Charlotte counties, with the capability to expand across South Florida. Rather than presenting static flood maps, the dashboard will allow stakeholders to select locations, sea-level-rise scenarios, projection years, and tidal conditions and then query the results using natural language. The underlying model identifies inundated areas where land elevation is below the selected water level and retains only areas hydraulically connected to the coast, producing maps of flood extent and depth. Using a retrieval-augmented generation framework, the LLM will interpret these geospatial outputs and ground its responses in project datasets, regional reports, and scientific literature while providing source references, confidence information, and clear model limitations. The open-source platform will integrate the existing Python workflow with an interactive web interface, regional geospatial datasets, scenario comparison tools, downloadable results, and an AI-assisted question-and-answer system. For example, a local planner could ask: “Under the 2100 SSP5-8.5 sea-level-rise scenario combined with a King tide, which communities in Lee County are potentially inundated, and what flood depths are projected?” This project will improve access to complex flood information and support climate-resilience planning for non-expert stakeholders while clearly presenting the bathtub model as a screening-level tool rather than a dynamic hydraulic forecast.
